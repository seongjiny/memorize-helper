# 2. 읽기 전용 모드

상태: 기획 초안. 여기서 ‘읽기’는 본문을 항상 펼쳐 보여주는 모드를 뜻합니다.
계정이나 자료 편집 권한을 읽기 전용으로 제한하는 의미와는 별개의 제안입니다.

## 목표와 첫 구현 범위

사용자가 줄을 잘못 눌러 본문이 가려지는 일 없이 성경을 읽고, 같은 자료에서 암송 연습으로
자연스럽게 전환할 수 있게 합니다. 기존 JSON 자료로 구현 가능하며 성경 DB는 필수가 아닙니다.

- 본문 상단에 `읽기 / 암송` 전환을 둡니다. 기존 사용 흐름을 위해 첫 기본값은 암송을 추천합니다.
- 읽기에서는 모든 절을 공개하고 줄 클릭 가리기 동작을 해제합니다. 텍스트 선택·복사를 허용합니다.
  실제 복사 허용 범위는 판본 이용 조건을 확인합니다.
- 글자 크기·다크 모드·소제목 표시 설정은 계속 사용합니다.
- 읽기에서는 전체 가리기/열기와 암송 기록 버튼을 숨깁니다. 기록 화면으로 가는 메뉴는 유지합니다.
- 읽기만 했다는 이유로 암송 기록이나 꾸준함 날짜를 생성하지 않습니다.
- 첫 단계는 현재 자료 읽기까지입니다. 전체 성경 탐색·읽기 계획·읽기 완료 기록은 별도 확장입니다.

## 사용자 흐름과 화면

1. 자료 카드 선택 → 기존 본문 화면 진입.
2. 상단의 ‘읽기’ 선택 → 본문 전체 표시, 가림 조작 제거.
3. 글자 크기·다크 모드로 읽기 환경 조절.
4. ‘암송’ 선택 → 기존 연습 화면 복귀.

```text
산상수훈
[읽기] [암송]                   판본 / 범위
마태복음 5장
팔복
1. 본문 전체 표시...
2. 본문 전체 표시...
```

모드 전환은 메뉴 안에만 넣기보다 본문 상단에서 발견할 수 있게 합니다.
선택 상태는 색상과 텍스트/형태로 함께 표시합니다. 읽기 본문에 불필요한 카드 장식을 추가하지 않습니다.

## 상태·설계

- 경로 제안: 기존 `/script/:id`에 `?mode=read` 또는 `?mode=memorize`를 사용합니다.
  없는 값·잘못된 값은 기본 암송 모드로 처리합니다.
- 첫 단계에서는 모드 전역 저장보다 URL을 기준으로 사용합니다. 읽기 링크 공유·새로고침·뒤로 가기가
  같은 모드를 유지하고, 기존 자료 링크는 기존 기본 동작을 유지합니다.
- 같은 자료에서 읽기로 전환해도 암송의 가림 상태는 별도로 보관합니다.
  다시 암송으로 돌아오면 전환 전 가림 상태를 복구합니다.
- 읽기 표시를 기존 ‘전체 열기’로 구현하지 않습니다. 현재 전체 열기는 열어본 절 범위를 수집하므로
  읽기를 사용했을 뿐인데 기록 기본 범위가 자료 전체가 되는 문제를 방지합니다.
- 자료를 바꾸면 기존처럼 가림 상태·열어본 절을 초기화합니다.
- 읽기는 마지막 암송 기록 위치로 자동 이동하지 않는 방향을 추천합니다. 읽기 위치 이어보기는 별도 요구입니다.
- 기록 입력창이 열린 상태에서 모드 변경을 허용할지 정합니다. 첫 단계는 창을 닫은 뒤 전환하도록 구성합니다.

관련 구현 위치: `ScriptView.vue`, `App.vue`, `useScriptRevealControls.ts`, 라우트 쿼리 해석.
본문 데이터 형식과 기록 테이블 변경은 필요하지 않습니다.

## 테스트할 것

| 경우 | 기대 결과 |
| --- | --- |
| 읽기 모드에서 줄 클릭 | 본문이 가려지거나 열어본 범위가 바뀌지 않음 |
| 읽기에서 암송으로 복귀 | 같은 자료의 기존 가림 상태와 연습 범위 유지 |
| 자료를 변경 | 이전 자료의 상태가 새 자료에 섞이지 않음 |
| 읽기 URL 새로고침·공유·뒤로 가기 | 모드가 URL과 일치 |
| 모드 값 누락·오류 | 기본 암송 모드로 정상 진입 |
| 읽기 화면의 메뉴 | 가리기/열기·암송 기록 조작 미노출 |
| 비로그인 읽기·인증 변경 | 본문 이용 가능, 기록 자동 생성 없음 |
| 320px·52/60px 큰 글씨·다크 모드 | 본문 읽기·전환 버튼 사용 가능, 텍스트 잘림 없음 |
| 키보드·스크린 리더 | 전환 버튼에 접근 가능하고 현재 모드를 알 수 있음 |

## 완료 기준과 결정할 사항

읽기에서는 본문이 항상 보이고 암송 상태·기록을 변경하지 않으며, 암송으로 복귀해 기존 연습을
이어갈 수 있으면 완료입니다. 기존 기록 저장 회귀 테스트도 통과해야 합니다.

1. 의미: 펼쳐 읽기 / 전체 성경 리더 / 보기 권한 제한. 현재 초안은 펼쳐 읽기.
2. 기본값: 기존 암송 / 읽기. 추천은 기존 암송.
3. 기억 범위: URL만 / 마지막 모드를 기기에 저장. 추천은 URL부터.
4. 읽기 기록: 없음 / 별도 읽기 완료 기록. 추천은 첫 단계 없음.
