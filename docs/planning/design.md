# 공통 디자인과 이미지 제작 계획

상태: 텍스트 설계 초안. 기능 의미와 화면 구조를 먼저 검토하고 실제 시안·이미지는 그다음 제작합니다.

## 디자인 방향

성경 본문 읽기를 중심에 두고 기존 앱의 단순한 구성·큰 글씨·다크 모드를 이어갑니다.
새 기능은 홈의 기록 요약, 본문의 모드 전환, 성취 화면, 별도 관리자 영역에 배치합니다.

| 영역 | 기준 |
| --- | --- |
| 일반 화면 | 현재 약 520px 본문 폭을 출발점으로 모바일 우선 검토 |
| 관리자 화면 | 넓은 화면에서는 목록/편집 분리, 모바일에서는 세로 배치 |
| 기본 동작 | 버튼 이름으로 읽기·암송·시험 차이를 설명 |
| 색상 | 기존 녹색 진행 강조와 회색 바탕 재사용; 다크 모드 토큰 함께 정의 |
| 날짜 상태 | 기록 있음, 오늘, 선택일, 미래일을 기호·테두리·텍스트로 구분 |
| 배지 | 작은 크기에서도 구분되는 단순한 형태와 명확한 이름 |
| 문구 | ‘기록한 날’, ‘기록 범위’, ‘자기 확인’처럼 데이터의 의미를 명시 |

홈에 달력·배지·자료 카드를 모두 큰 카드로 쌓으면 자료 진입이 멀어집니다.
첫 시안은 달력 한 영역과 짧은 성취 링크를 넣고, 배지 전체 목록은 별도 화면에 둡니다.

## 정보 구조 제안

```text
홈
├─ 나의 기록 요약·달력 → 기존 기록 화면
├─ 나의 성취 → 배지 목록·조건 상세
└─ 자료 목록
   └─ 본문: 읽기 / 암송
      └─ 시험하기 → 준비 → 진행 → 결과 → 재연습

메뉴: 개인 설정 / 기록 / 성취 / 업데이트 / 로그인
관리자만: 관리자 → 자료 / 사용자 / 운영 이력
```

읽기·암송은 같은 본문의 보기 방식이고 시험은 준비·진행·결과가 있는 작업이므로,
시험 시작을 곧바로 모드 탭 클릭으로 처리하기보다 준비 화면을 거치도록 추천합니다.

## 먼저 만들 시안

| 시안 | 포함할 상태 | 검토 목적 |
| --- | --- | --- |
| 홈 | 로그인·비로그인·기록 없음·오류·기록 있음 | 달력 높이와 자료 진입 거리 |
| 본문 | 읽기·암송·큰 글씨·다크 모드 | 상태 구분과 본문 집중 |
| 시험 | 준비·마이크 권한·녹음·채점 중·판정 보류·점수/오답 결과 | 점수와 인식 오류를 구분하는지 |
| 성취 | 달성·진행·계산 오류·배지 상세 | 조건과 수치가 명확한지 |
| 관리자 | 목록·초안·미리보기·게시 전 확인·권한 없음 | 작업 실수와 권한 오해 방지 |

각 기능은 텍스트 흐름 → 간단한 와이어프레임 → 실제 컴포넌트 시안 순서로 검토합니다.
320px/390px 모바일과 데스크톱, 기본 글씨와 최대 글씨, 밝은/어두운 테마를 포함합니다.

## 접근성·사용성 확인

- 주요 터치 버튼은 약 44px 영역을 목표로 하고 달력 날짜도 충분한 간격을 확보합니다.
- 키보드 포커스가 보이고 화면의 이동 순서와 일치해야 합니다.
- 대화상자에는 이름·포커스 이동/복귀·닫기 경로를 제공합니다.
- 일반 본문 텍스트는 대비 4.5:1을 기준으로 검토합니다. 큰 글씨와 UI 경계는 해당 기준을 따릅니다.
- 상태를 색만으로 알리지 않습니다. 배지 잠금·날짜 기록·오류에 텍스트나 기호를 함께 둡니다.
- 시험 단계 변경과 오류는 스크린 리더에 알리되 긴 원문을 매번 불필요하게 읽지 않도록 검토합니다.
- 동작 줄이기 설정을 존중하고 배지 축하 애니메이션은 필수 정보를 대신하지 않게 합니다.
- 본문 글자 확대가 관리자 표의 조작이나 달력 날짜를 깨뜨리지 않도록 영역별 레이아웃을 확인합니다.

## 이미지가 필요한 곳과 제작 방식

| 자산 | 첫 단계 필요성 | 방식 |
| --- | --- | --- |
| 모드·달력·관리 버튼 아이콘 | 낮음; 텍스트만으로 시작 가능 | 기존 스타일과 맞는 SVG 아이콘 |
| 배지 4종 | 성취 시안 이후 검토 | 단순 SVG 우선, 생성형 이미지로 스타일 탐색 가능 |
| 기록 없음 안내 그림 | 선택 사항 | 작고 차분한 삽화, 문구·버튼은 실제 UI로 작성 |
| 전체 화면 목업 이미지 | 선택 사항 | 분위기 검토 참고용; 실제 UI의 날짜·수치·문구 검증은 컴포넌트로 수행 |
| 성경 본문·판본 문구 | 생성 이미지 대상 아님 | 검수된 텍스트를 실제 화면에 표시 |

현재 단계에는 기능 합의가 먼저라서 이미지를 생성하지 않았습니다.
필요한 자산·제작 브리프는 아래와 같이 준비해 두고, 배지 방향을 선택하면 시안 제작에 사용합니다.

### 배지 스타일 탐색용 브리프

- 목적: 성취 화면의 작은 배지 아이콘 4종.
- 주제: 첫 기록(펼친 책), 3일 이어가기(연결된 세 점), 10일의 발자국(달력 체크), 모든 절 기록(책과 체크).
- 분위기: 차분함·격려, 선명한 외곽 형태, 기존 녹색과 회색에 맞는 적은 색.
- 제약: 글자·숫자·판본 로고·특정 인물을 넣지 않음. 실력 인증이나 공식 판본 보증처럼 보이지 않게 함.
- 형태: 1:1 정사각형, 투명 배경, 가장자리 여백, 24/48px에서도 알아볼 수 있는 구조.

이미지 생성 프롬프트 예시:

> Create one simple achievement icon for a Bible memorization journal. Subject: an open book
> with a small check mark, representing a first saved practice record. Calm, minimal flat
> illustration, green and neutral gray palette, bold readable silhouette, centered square
> composition, generous padding, transparent background. No text, numbers, logos, seals,
> or detailed scenery. Match a consistent four-icon family and remain recognizable at 48px.

네 주제는 각각 생성하고 같은 외곽선·색·그림자 수준으로 검수합니다. 최종 앱 아이콘은 필요하면
SVG로 다시 그려 크기·색·접근성을 제어합니다. 잠금 상태는 다른 그림을 새로 만들기보다 실제 UI에서
이름과 상태를 표시합니다.

### 빈 기록 안내 삽화 브리프

주제는 책과 빈 달력, 목적은 첫 기록 버튼을 돕는 안내입니다. 텍스트와 버튼을 그림 안에 넣지 않고
투명 배경의 작은 삽화로 제작합니다. 본문과 행동 버튼보다 시각적 비중이 작아야 합니다.

## 자산 검수와 전달물

- 원본·생성 프롬프트·사용 근거·수정 내역과 최종 SVG/WebP/PNG를 보관합니다.
- 실제 모바일 크기와 다크 모드에서 외곽·대비·잘림·투명 배경을 확인합니다.
- 장식 이미지는 빈 대체 텍스트, 의미 있는 이미지는 기능을 설명하는 대체 텍스트를 제공합니다.
- 배지 조건·시험 평가·성경 본문은 이미지 안의 텍스트에 의존하지 않습니다.
- 최종 전달물은 기능별 화면 흐름, 상태별 시안, 공통 스타일, 필요한 아이콘, 접근성 검토 결과입니다.
