# 4. 성취·배지 (Achievement)

상태: 기획 초안. 첫 범위는 저장된 암송 기록으로 확인 가능한 성취입니다.

## 목표와 첫 범위

사용자가 쌓아온 기록을 알아보고 다음 작은 목표를 선택하게 합니다.
순위 경쟁보다 개인의 기록과 꾸준함을 격려하는 방향을 추천합니다.

첫 배지는 네 가지 규칙으로 시작합니다. 아래 수치는 검토용 후보입니다.

| 배지 후보 | 달성 조건 | 진행 표시 |
| --- | --- | --- |
| 첫 기록 | 암송 기록이 1일 이상 있음 | 0 / 1일 |
| 3일 이어가기 | 기록 날짜가 3일 이상 연속인 구간이 있음 | 최장 연속 N / 3일 |
| 10일의 발자국 | 서로 다른 기록 날짜가 총 10일 이상 | N / 10일 |
| 한 자료의 모든 절 | 특정 자료의 고유 절 기록 범위가 전체를 포함 | N / 전체 절 수 |

‘한 자료의 모든 절’은 저장 범위를 뜻합니다. ‘성경 완전 암기’ 같은 실력 인증으로 표현하지 않습니다.
전체 절을 모두 포함했는지는 정확한 개수로 판정합니다. 현재 카드의 반올림된 100%를 달성 조건으로
사용하지 않습니다. 예를 들어 500절 중 499절은 표시가 100%여도 완성이 아닙니다.

첫 단계는 포인트·보상·공유·리더보드 없이 배지 목록과 진행 상태를 보여줍니다.
시험 점수 배지는 시험 방식과 저장·채점 정책이 결정된 뒤 별도로 추가합니다.

## 판정 정책

- 달력과 동일하게 저장된 암송 기록의 `record_date`를 기준으로 합니다.
- 기존/과거 입력 기록을 포함합니다. 현재 기록은 실제 당일 활동을 인증하는 데이터가 아닙니다.
- 연속 기록은 서로 다른 날짜가 하루 간격으로 이어진 최대 구간과 현재 구간을 각각 계산합니다.
- 현재 구간은 오늘 기록이 없더라도 어제까지 이어졌다면 유지합니다. 오늘 추가 기록 기회가 남아 있기 때문입니다.
- ‘3일 이어가기’ 배지는 최장 구간으로 판정합니다. 오늘 쉬더라도 과거의 3일 구간이 남아 있으면
  달성 상태를 유지합니다. 현재 연속 기록은 달력 요약에서 따로 보여줍니다.
- 같은 날짜는 수정 횟수와 무관하게 1일입니다. 미래 날짜는 집계하지 않습니다.
- 첫 단계는 기록에서 성취를 다시 계산하는 방식을 추천합니다. 기록 삭제·수정으로 조건이
  사라지면 해당 배지는 현재 달성 상태에서 해제됩니다. 이 정책을 사용자에게 설명합니다.
- 달성일이 필요하면 조건을 처음 만족한 기록 날짜를 계산할 수 있지만, 실제 배지를 받은 시각이나
  실제 활동 인증일로 표현하지 않습니다. 첫 단계는 날짜 표시 없이도 가능합니다.

배지를 영구 보관하려면 서버 판정과 `user_achievements` 저장이 별도로 필요합니다.
영구 배지와 현재 진행률을 구분하고, 기록 삭제·계정 삭제·소급 지급·정책 변경을 함께 정해야 합니다.
확정 전에는 브라우저 `localStorage`를 배지의 원본 데이터로 쓰지 않습니다.

## 화면과 사용자 흐름

1. 메인 달력 요약의 ‘나의 성취’ 또는 메뉴에서 성취 화면 진입.
2. 달성한 배지와 진행 중 배지를 확인.
3. 배지 선택 → 정확한 조건·현재 값·관련 자료 확인.
4. ‘기록 보기’ 또는 자료 연습으로 이동.

```text
나의 성취
기록으로 쌓아온 작은 목표를 확인해 보세요.
[첫 기록 ✓] [3일 이어가기 2/3] [10일의 발자국 6/10]
[한 자료의 모든 절 42/111]

배지 상세
조건: 암송 기록이 있는 날 10일
현재: 6일 / 다음 목표: 4일
[기록 보기]
```

잠긴 배지는 조건을 숨기지 않습니다. 부정적인 문구나 계속 뜨는 축하 모달을 피하고,
첫 단계는 목록의 달성 상태 표시만으로 시작합니다. 비로그인에는 기능 설명과 로그인 경로를 제공합니다.

## 설계와 하위 작업

날짜 집계는 달력과 공통 함수로 관리하고, 자료별 고유 절 집계도 현재 홈의 진행률 계산과
동일한 원본을 사용하도록 추출합니다. 계정별 기록 조회 성공 이후에만 판정합니다.
자료 본문 조회 실패 시 자료 완성 배지는 ‘계산할 수 없음’을 보여주며 미달성으로 단정하지 않습니다.

- [ ] 배지 이름·조건·수치·삭제 시 정책 확정.
- [ ] 날짜별 활동·현재/최장 연속 기록·정확한 범위 집계 함수 준비.
- [ ] 배지 정의 ID와 조건을 중앙 관리하고 판정 결과와 표시 문구를 분리.
- [ ] 성취 목록·상세·빈 상태·조회 실패·비로그인 화면 구현.
- [ ] 아이콘 스타일 확정. [디자인 문서](design.md)의 제작 기준 사용.
- [ ] 영구 보관·축하 알림은 선택되면 별도 작업으로 진행.

## 테스트할 것

| 경우 | 기대 결과 |
| --- | --- |
| 기록 없음 → 첫 기록 추가 → 삭제 | 제안 정책에 따라 미달성 → 달성 → 미달성 |
| 10일 기준의 9/10/11일 | 경계에서만 달성, 같은 날짜 수정은 증가 없음 |
| 월말·연말·윤년을 가로지르는 3일 | 실제 연속 날짜로 달성 |
| 하루 공백·오늘 기록 없음 | 현재/최장 구간이 정책대로 계산 |
| 과거 기록 추가·날짜 수정 | 모든 영향을 받는 조건을 다시 계산 |
| 동일 절 중복 기록·범위 겹침 | 고유 절을 한 번만 집계 |
| 500절 중 499절 | 반올림 표시와 관계없이 완성 배지 미달성 |
| 본문 또는 기록 조회 실패 | 잘못된 배지를 지급하지 않고 오류/재시도 제공 |
| 사용자 A → B·로그아웃 | A의 배지·진행 상태가 남지 않음 |
| 기기 자정 경과 | 현재 연속 기록 상태가 최신 날짜 기준으로 갱신 |

## 완료 기준과 결정할 사항

조건과 화면 문구가 일치하고, 기록 수정·삭제·계정 전환 후에도 배지 상태가 정확하면 완료입니다.
날짜 집계는 메인 달력과 같은 예제로 검증합니다.

1. 배지 방향: 꾸준함 / 분량 / 시험 실력. 추천은 꾸준함과 기록 범위부터.
2. 배지 유지: 현재 기록으로 재계산 / 한번 받으면 영구 보관. 추천은 재계산부터.
3. 과거 기록: 포함 / 도입 후 활동만. 추천은 포함.
4. 표현: 조용한 상태 표시 / 축하 알림·이미지. 추천은 상태 표시부터.
